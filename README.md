# nix-session-search

Nix-packaged session history indexing and search for agent workflows.

## Initial Scope

- ingest local agent transcripts and logs
- normalize metadata across providers and sessions
- support fast local full-text search with filters
- surface reusable prior solutions for recurring infra tasks
